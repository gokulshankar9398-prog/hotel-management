01 / Engineering Methodology

Problem Statement & Solution Architecture

The Industry Challenges

  • Client-Side OTP Leaks: Naive booking applications leak OTP passcodes in JSON API responses or the frontend DOM.
  • Complex Multi-Gateway Friction: Rigid booking forms fail when international SMS routes fail or impose hefty gateway fees.
  • Fragmented Admin Tooling: Lack of unified real-time visibility into reservations, check-in states, and security audit logs.

The Grand Royale Methodology

  • Zero-Exposure SHA-256 Storage: Passcodes are hashed on the backend with 5-minute TTL expirations and instant deletion upon use.
  • Brevo Transactional Pipeline: High-deliverability email dispatch with luxury HTML email templates and terminal fallback.
  • Unified Executive Command Center: Dual-auth portal (`/admin`) with live KPI metrics, status CRUD, and audit telemetry.

03 / Backend Engineering

Backend Implementation & Security Architecture

Cryptographic Passcode Protection

When an OTP is generated, the plaintext is never stored raw. It is converted to a SHA-256 digest: crypto.createHash("sha256").update(otpCode).digest("hex") Upon submission, the guest's input is hashed and compared using timing-safe logic.

Replay Attack Defense & Expiry

Passcodes expire strictly in 300 seconds (5 minutes). Immediately after successful verification, the record is purged from the Map store (bookingOtpStore.delete(key)), preventing replay attacks.

Atomic Reservations Sync

Bookings are assigned unique identifiers (e.g., GR-892104), validated, and written to bookings.json, feeding real-time updates directly to the Admin Command Center.

server.js (Security Pipeline Snippet) Zero-Leak Guard 
const crypto = require("crypto");
const hashedOtp = crypto
    .createHash("sha256")
    .update(otpCode)
    .digest("hex");

bookingOtpStore.set(cleanEmail, {
    hashedOtp,
    expiresAt: Date.now() + 300000,
    attempts: 0
});

// Response sent to frontend (NEVER contains otpCode!)
res.end(JSON.stringify({
    success: true,
    expiresInSeconds: 300,
    message: "Verification passcode dispatched"
}));
